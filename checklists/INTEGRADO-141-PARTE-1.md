# Checklist integrado — Parte 1: pedido, layout e grid

**Origem:** `StopBall_CHK-DES-GERAL-001_Checklists_Integrados_v0.2.docx`, tabelas de verificações (13/11/2026).  
**Situação:** transcrição textual para Markdown em revisão, preservando códigos e texto. Não equivale à homologação nem substitui evidências de arquivo real.

**Legenda da fonte:** `O` obrigatório quando a etapa existe; `C` condicional; `V` validação pendente; `A` registro/automação preferencial. O operador deve marcar **Conferido / Pendente / Não se aplica**, com justificativa quando necessário.

## PED — Conferência inicial do pedido (12)

| ID | Tipo | Verificação |
|---|---|---|
| PED-01 | O | Ler pedido vigente e todas as observações, inclusive alterações em destaque. |
| PED-02 | O | Conferir cliente, número do pedido, sublistas e vínculo com o layout. |
| PED-03 | O | Conferir quantidade, tipo de peça, tamanho, gênero/modelagem por sublista. |
| PED-04 | O | Conferir manga, capuz, bolso, punho, bainha e acabamento previsto. |
| PED-05 | O | Identificar a última versão aprovada; conferir diferenças frente à saída anterior. |
| PED-06 | C | Comparar layouts visualmente semelhantes sem deduzir que são iguais. |
| PED-07 | C | Confirmar nomes, números e aplicação por peça quando lista/layout divergem. |
| PED-08 | C | Confirmar versões de escudo em camisa, short e outras peças. |
| PED-09 | C | Conferir todos os patrocínios e cores previstos em cada versão. |
| PED-10 | O | Verificar qualidade, excedente e capacidade de edição do arquivo recebido. |
| PED-11 | C | Dúvida sobre RGB/bitmap/PNG ou alteração de cor foi avaliada e esclarecida. |
| PED-12 | C | Inconsistências resolvidas e decisão do vendedor vinculada ao pedido. |

## LAY — Criação do layout (11)

| ID | Tipo | Verificação |
|---|---|---|
| LAY-01 | O | Criar layout a partir do pedido e referência corretos, por sublista. |
| LAY-02 | C | Identificar variantes para cor, linha, goleiro e modelagem; não homogeneizar diferenças. |
| LAY-03 | C | Conferir versão, posição, grafia e legibilidade de todos os logos e patrocinadores. |
| LAY-04 | C | Conferir escudos, tipo de aplicação e diferenças entre peças. |
| LAY-05 | C | Manter originais de patrocinadores/logos na última página, conforme prática interna. |
| LAY-06 | C | Preparar bandeiras antes de redução proporcional quando a rotina aprovada exigir. |
| LAY-07 | C | Conferir coerência entre arte de linha e goleiro sem anular variantes previstas. |
| LAY-08 | O | Verificar viabilidade de bitmap/PNG, nitidez, excedente e capacidade de mudança de cores. |
| LAY-09 | C | Validar legibilidade funcional de QR Codes e elementos reconstruídos. |
| LAY-10 | O | Identificar revisão aprovada e registrar alterações antes da entrega à saída. |
| LAY-11 | C | Encaminhar ao vendedor/responsável a dúvida não resolvida; não improvisar. |
